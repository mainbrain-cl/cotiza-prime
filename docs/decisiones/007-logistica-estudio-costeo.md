# 007 · Logística: primer rubro especializado, tras un estudio de costeo

**Estado:** aceptada · **Fecha:** 2026-09-30 · **Detalle en:** `PROYECTO.md` §9.3

## Contexto

Logística es el rubro de interés principal, pero un modelo de flete mal hecho hace cotizar bajo el costo.

## Decisión

Logística es el **primer rubro especializado** y la primera prioridad después del lanzamiento (M20). Antes de programarlo se hace un **estudio de costeo** validado con dos o tres empresas reales. El estudio parte en paralelo desde la fase 0.

## Por qué

Un buen modelo de flete no se inventa: depende de costos por km, costos fijos, tramos, retorno vacío, peajes y combustible.

## Alternativas descartadas

- Calculadora de flete en el lanzamiento, sin estudio

## Consecuencias

Mientras tanto, logística puede cotizar con el modelo general "por unidad".
